# HarmonyMap

和弦與音階視覺化工具。選一個根音、挑一個和弦或音階,就在鋼琴鍵盤上看到它是哪幾個音、
每個音是第幾級、該怎麼拼寫,還可以直接聽。

開啟方式:用瀏覽器打開 `index.html`(單一檔案,沒有相依套件,離線也能用)。

## 功能

**和弦(67 種)** — 按**和弦家族**分組,而不是按音數:大調系、屬和弦系、小調系、
減系與半減系、無三度和弦(掛留與強力)、增六和弦。家族由三音 + 七音決定,
也就是決定和弦功能與可搭配音階的那兩個音;組內再照張力音由少到多排列。

三條篩選軸可以疊加使用:**風格**(古典/流行搖滾/爵士/藍調靈魂/影視配樂)、
**程度**(必學/常見以上)、**編制**(三和弦/七和弦與加音/延伸與變化)。
例如「流行 × 三和弦」會篩出 6 個,「古典」會篩出 18 個。

每個和弦顯示組成音、級數公式、半音間隔、用法說明,以及可以搭配的音階(點一下直接跳過去看)。

**音階(95 種)** — 大調七聲調式、和聲小調系統、旋律小調系統、五聲與藍調、
**日本音階**(平調子、雲井調子、都節、陰旋、岩戶、琉球、律、民謠、呂)、
**阿拉伯與中東**(希賈茲、希賈茲卡爾、納哈萬德、庫爾德、阿賈姆、巴亞提、拉斯特、薩巴、
尼克里茲、納瓦阿薩爾、蘇茲納克、贊賈蘭、阿薩爾庫爾德、波斯)、
**印度與其他亞洲**(十大塔特、中國宮商角徵羽、印尼貝洛與斯連德羅)、
對稱音階、其他七聲音階、Bebop 八聲音階,冷門的(梅湘七個有限移調模式、普羅米修斯、
謎音階、三全音音階、伊斯特里亞等)收在「進階與罕用」。

七聲音階另外附上完整的順階和弦表(三和弦 + 七和弦 + 羅馬數字),點表格裡的七和弦可以直接
跳去看它的組成音;同一組音在不同傳統裡的別名也會列出來(例如希賈茲 = 弗里吉安屬音階、
羽調式 = 小調五聲、拜拉夫 = 雙和聲大調),一樣可以點擊跳轉。

**反查** — 直接在鍵盤上點幾個音,列出所有名字符合的和弦(含轉位),
以及「再多幾個音就會變成什麼和弦」。

**其他** — 點和弦或音階名稱就直接發聲(再點一次重播),不另外設播放按鈕;
齊奏/琶音/逐音上下行三種試聽方式、琴鍵上可切換標示音名/唱名/級數、
深色與淺色主題、鍵盤快捷鍵(↑↓ 換和弦與音階、←→ 換根音、空白鍵播放)。

音源與 ScrollScore 相同:Salamander 真實鋼琴取樣,第一次碰到頁面就開始預載,
抓不到(離線或 CDN 被擋)時自動退回合成音色備援。響度也照 ScrollScore 的做法補上
母帶級的響度壓縮,實測積分響度合成備援 -9~-10 LUFS、取樣路徑 -5 LUFS,
都大於 YouTube 的 -14 LUFS 正規化基準,峰值仍在 0 dBFS 以下沒有削波。

## 音名拼寫

音名不是用「12 個音查表」查出來的,而是照樂理規則推導:
字母 = 根音字母 +(級數 − 1),升降記號 = 目標音高 − 該字母的自然音高。

所以 Cdim7 會正確地拼成 **C E♭ G♭ B♭♭**(而不是 C D♯ F♯ A),
F♯7♯9 是 **F♯ A♯ C♯ E G♯♯**,D♭13 是 **D♭ F A♭ C♭ E♭ B♭**。
同一個級數只會用一個字母,所以會出現重降、重升音,這是正確的寫法。

## 與 ScrollScore 的關係

鍵盤的繪製邏輯(`isBlackKey` / `KB_*` / `computeKeyboardHeight` /
`rebuildKeyboardRange` / `drawKeyboard`)直接沿用 [ScrollScore](https://github.com/stevenmusic/ScrollScore)
的實作,連常數與註解都保持原樣,只把原本「左右手聲部」的顏色語意改讀成
「根音 / 其他組成音」。頂欄品牌名的字型、字級、字距與各斷點行為也與 ScrollScore 完全相同,
兩個工具放在一起看是同一個產品。

音源也一樣:主音源是 Salamander 鋼琴真實取樣(Tone.js 官方託管的完整版),
取樣清單、最近取樣 + playbackRate 補音高、同和弦共用錄音、衰減時間常數、
依音高擺左右的聲像與殘響送出,全部照 ScrollScore 的實作與參數;
取樣抓不到時退回的合成音色備援同樣沿用它的合成器設定。
