# 字典、辨識、雙語、播放方式、快捷鍵

> 這份是從 CLAUDE.md 拆出來的細節規則,要改相關功能時才讀。整體的硬性規則在 CLAUDE.md。

## 字典
- 和弦 80 種、音階 121 種(14 組;旋律小調系統 8 個:七個調式 + 古典旋律小調)
- 音階分組:大調七聲調式、和聲小調系統、旋律小調系統、和聲大調系統、雙和聲大調系統、
  五聲與藍調、日本、阿拉伯與中東、印度與其他亞洲、非洲、對稱、其他七聲、Bebop、進階與罕用。
  **母音階有七個調式的就要七個都列**——只放母音階、不放調式,等於承認這本字典不完整
  (和聲大調與雙和聲大調原本就只有母音階,散在「其他七聲音階」裡)
- **和弦按「家族」分組,不要按音數分組**。家族由三音 + 七音決定(大調系/屬和弦系/小調系/
  減系與半減系/無三度/增六),因為那才決定和弦的功能與可搭配的音階。按音數分組會把
  maj7→maj9→maj13 拆散,又把 maj7/7/m7/dim7 綁在一起(它們取五種完全不同的音階)
- 組內順序照張力音堆疊(三和弦 → 四音 → 五音以上),三和弦永遠排在家族最前面
- 風格、常用度、編制都是**篩選**不是分組。分組放錯會把和弦藏起來,篩選只是縮小範圍;
  而且風格是「誰常用它」(上下文),不是和弦的內在屬性
- 功能(主/屬/下屬)不能當分組軸——功能是上下文的屬性,同一個和弦在不同調裡功能不同。
  唯一的例外是增六和弦,它本來就是由解決方向定義的
- 音階維持按母音階系統與文化來源分組,那本來就是對的,不要跟著和弦一起改
- 跨文化同音異名(希賈茲 = 弗里吉安屬音階、羽調式 = 小調五聲…)是刻意保留的重複條目,
  **不要刪**——有人就是要查「拜拉夫」,刪掉等於這本字典對他失效。
  阿拉伯 10/14、印度 10/17 與西方音階同音高,處理方式是:
  晶片右上角標 `≡`(滑過去看得到等於誰)+ 一個「隱藏同音重複」開關(120→82)+
  結果面板互相連結。開關打開時搜尋仍然找得到被隱藏的條目,否則會幫倒忙
- 同音高不等於同一個東西:馬卡姆的拉斯特/巴亞提定義音是四分之一音(鋼琴只能近似),
  印度的塔特只是拉格的母音階(拉格還要看上行下行、vadi、演奏時辰)。說明欄要寫清楚
- 新增條目後跑一次「全部項目 × 21 個根音」的驗證(`tests/run.js` 的「字典 × 21 根音」那組):
  拼寫、MIDI 自洽、音階內不得有重複音高、七聲音階七個字母各一次。
  兩種情形**不算錯**,寫驗證時要排除:級數本身就重複的音階(導音全音有 ♭7 與 7、
  佛朗明哥有 ♭3 與 3);以及需要三重升降時 `spell()` 刻意退回等音簡易拼寫(`acc` 為 null)
- 說明文字(`d` / `d_en`)也要照樂理逐條核對過(80 和弦 + 120 音階讀過一遍,修了 12 處:maj7♭5 不是 maj7♯11 的同一組音、
  7♭9♭13 對應弗里吉安屬音階、m♭6 = ♭6 為根音的 maj7 第一轉位、大洛克里安是拿坡里大調第五級…)。
  說明裡「X 的第 N 級」有測試逐一比對實際的音
- **建議音階(`CHORD_SCALES`)必須包含和弦的每一個組成音**(和弦音階理論),每個和弦至少一個,測試逐一檢查。
  有完全五度的 7♭9 / 7♭13 / 7♭9♭13 不能配 altered(它沒有完全五度),改用 dimHW / phrygDom / mixob6;
  7♯9 用 dimHW 與九音藍調(blues9,含大三度);增六和弦照它同音的屬七用 lydianDom
- 順階和弦表的名稱是照音高比對的,拼法可能跟三度堆疊不同(雙和聲小調 iii = E G B D♭,聽起來是 Em6 = E G B C♯):
  名稱照寫、旁邊標金色 **≅**,表下寫圖例。要三重升降的理論調(B♯ 起的增音艾奧尼安…)那幾列改用等音拼寫並標 ≅。
  測試檢查每一列:拼法不同卻沒標 ≅ 算錯
- 新增和弦時 `alias` 可以省略,讀的地方一定要 `def.alias && def.alias.length`——
  少了前半段,沒寫 alias 的和弦一點下去整頁就掛掉(踩過)

## 反查(和弦辨識)
- 介面上的名稱是「**辨識**」(分頁)/「辨識和弦」(卡片標題),英文 Identify / Identify Chord(使用者要求換成好懂的說法;
  「反查」是查字典的術語,第一次看的人不知道要做什麼)。程式與文件裡仍沿用 find / 反查當內部名稱
- 低音不是根音時要寫成**斜線和弦**:E G C 是 `C/E`,不是 `C`。和弦名稱說的是
  「這是哪一組音」,斜線後面說的是「最低的是哪一個音」,只寫 C 的話照著彈出來的
  聲音跟使用者選的不一樣。「這些音可以屬於」那一列也照同一套規則(`C6/E`)
- 斜線後面那個低音的拼寫**要照那個和弦自己的級數推**(`chordSpelling()`),
  不能用升降偏好硬拼——不然 C7 的第三轉位會寫成 `C7/A♯` 而不是 `C7/B♭`。
  德國增六的 ♯6 本來就拼成 A♯,所以它顯示 `CGr+6/A♯` 是對的,不是 bug
- 排序維持「低音當根音的排前面,再來是組成音少的寫法」。斜線和弦是同一組音的
  另一種讀法,不是次等結果,所以不另外降權
- 轉位編號看的是**低音是第幾級**:三音 = 第一轉位、五音 = 第二轉位、七音 = 第三轉位,
  升降不影響編號(♭3 一樣是第一轉位)。2/4/6/9/11/13 在低音**沒有**標準的轉位編號——
  那些是掛留音與延伸音,不是三度堆疊的其中一層,`C13/A` 講「第五轉位」是自己發明的
  說法。這種情形只寫「轉位」,斜線和弦名稱已經把低音是誰講清楚了
- **拼寫預設「照調號(自動)」**(`spellPrefFor`):根音取調號升降記號比較少的寫法——大三度的和弦看大調
  (D♭ E♭ F♯ A♭ B♭)、小三度的看小調(C♯m E♭m F♯m G♯m B♭m)。原本一律用升記號,E♭7 變成 D♯7(三音 F𝄪)。
  選單的 ♯ / ♭ 是強制指定
- **省略五音**:沒有任何一般和弦完全符合時,補上「加回完全五度就符合」的讀法(C E B♭ D♯ = C7♯9,標「省略五音」)。
  有完全符合的就不補(E G C 不能多出 Em♭6(省略五音))
- 排序:完全符合的一般和弦 > 省略五音 > 增六和弦(增六要看解決方向,C E B♭ 先讀成 C7 省略五音);
  同一級裡低音當根音的先。`tests/run.js`「辨識命名」有 35 組常見音組合
- 每一種讀法各自算自己的編號:B C E G 同時是 `Cmaj7/B`(第三轉位)與
  `Em♭6/B`(第二轉位),不能拿第一名的編號套用到整份清單

## 中英雙語
- 介面文字只有**一份 DOM**,靠 `data-i18n` / `data-i18n-attr` + `applyLanguage()` 換字。
  動態產生的內容(清單、篩選列、鍵盤摘要、結果面板)不吃 `data-i18n`,換語言後要 `render()`
- **英文介面不附中文對照名稱**。中文介面的副標放英文原名(查資料、看譜都用得到)是對的,
  反過來在英文版塞一個中文名稱讀不出任何資訊,只是雜訊——所以 `subName()` 在英文介面
  回傳空字串,呼叫端要連分隔號一起省略(用 `nameWithSub()`),不然會留下孤零零的「 · 」。
  空字串也不要硬塞進 DOM:`.chip` 與 `.kb-summary` 都是 flex + gap,空的 `<i>` / `.zh`
  會白白撐出一段間距,沒有內容時連元素都不要產生
- `sym` / `alias` / `t`(公式)這幾個欄位是**語言中性**的樂譜符號,不能放中文。
  放了的話兩種語言都會顯示同一串中文(踩過:`quartal` 的 `sym` 曾經是「四度堆疊」,
  英文版就長出 `C四度堆疊`)。中文名稱放 `zh`、英文名稱放 `en`,說明放 `d` / `d_en`
- **換語言時上方的分頁(和弦/音階/辨識)與樂器切換(鋼琴/吉他)不能移位**(使用者要求):分頁 `flex:1 1 0` 三等分、
  樂器按鈕固定寬度(56px,≤380px 48px),寬度不跟著文字長短變(Identify、Guitar 比中文長)。有測試量位置
- 選中的分頁是粗體、比較寬:320px(≤340 字級小一階)與桌機左欄(內距 2px)都要放得下英文的「Identify」,測試逐一選中量
- 標點也要跟著語言換:別名的分隔號中文用「、」、英文用「, 」(`listSep`),
  英文句子裡不要出現全形空白 U+3000
- 新增條目時 `en` 與 `d_en` 是必填。少了就會退回中文,英文版立刻混進中文

## 播放方式
- 音階**不提供「齊奏」**:把一整個音階的音同時壓下去在音樂上沒有意義,
  那是和弦的呈現方式,音階是旋律性的,只給琶音與逐音上下行
- 每個分頁各自記住自己的播放方式(`PLAY_PREF`),在和弦選了齊奏、去音階看一眼
  (自動變成琶音)、再切回和弦時要回到齊奏,不要把音階的設定帶回來
- 音階的預設是**琶音**不是逐音上下行:逐音一次要跑十幾個音、長度是琶音的好幾倍,
  當「點一下聽聽看這個音階長怎樣」的預設太久;琶音快、一樣聽得出音階的顏色

## 快捷鍵(桌機)
- 空白鍵 = 播放(練習中 = 開始/停止)、↑↓ = 清單上下一個、←→ = 根音字母、字母 C~B = 根音、
  `-` / `=` / `+` `#` = ♭ ♮ ♯(不用 b 當降記號,會跟 B 撞)、練習中 Backspace = 刪除最後一個。
  練習中字母與升降設定的是輸入板的根音。輸入框、下拉選單有焦點時一律不攔

- 吉他音階分頁:點清單裡的音階、空白鍵、點摘要列(`playCurrent`)和點指板(`playScaleUp`)彈的是同一串音
  (`guitarScaleUpMidis()`:選了把位就是把位內每個音,選「全部」就是一個完整八度),不要讓清單那條路只彈 `displayNotes()`

- 鋼琴和弦分頁:點鍵盤方框內任何地方(琴鍵、沒亮的鍵、空白)= 整個和弦一起彈(`.kb-wrap` 的 pointerdown,跟音階一樣),
  不再只彈點到的單音;單音從摘要列的音名點。和弦分頁換根音(字母、♭ ♯)的瞬間就彈新和弦(`playAfterRootChange`)。吉他的和弦圖照舊各有自己的點擊
- 辨識結果(完全符合與「可以屬於」)都可以點,跳到那個和弦的和弦分頁,低音照選的音(`findJumpAttrs` / `goToParsedChord`);
  鍵盤操作 Enter 也行。三個音以上時另外列「包含這些音的音階」(`scalesContaining`):每個音階 × 12 根音,音都在裡面的留下,
  同一組音的不同調式只留一個(主音是低音的優先),依常用程度排序,最多 8 個,點了跳到音階分頁
- 辨識的斜線和弦名稱跟和弦頁用同一種寫法(`chordPageSpelling`):和弦頁的低音照和弦級數拼,根音拼法不對時會變重升重降
  (D♭13♭9 的低音 D 在和弦頁是 E♭♭),所以依序試偏好拼法 → 升 → 降,挑沒有重升重降的(C♯13♭9/D)。結果清單、摘要列、點下去的和弦頁三處一致
- 級數輸入:小調裡已經寫了 ♭ 的(i ♭VI ♭VII)不再降第二次;小寫 vii° / viiø 是導音上的(A 小調 G♯dim7);
  小寫一定是小三(imaj7 = mMaj7、iadd9 = m(add9)),找不到小調版本就算錯字,只有 sus、5 這種沒有三音的才照原記號
