## 換和弦練習
- **「進行」分頁**(使用者要求,2026-11):和弦 / 進行 / 音階 / 辨識(原本排第四,後來照使用頻率移到第二)(英文 Chord / Scale / Identify / Progs)。

  使用者一度想拿辨識分頁來換,討論後保留辨識(它是唯一「知道音查名字」的功能)。
  **內部狀態不變**:進行分頁 = `STATE.tab === "chord"` + `PRACTICE.open`,`#tabProg` 只是這個狀態的入口
  (分享連結、快捷鍵、全螢幕、兩欄版面都沿用)。點和弦/音階/辨識分頁 = `leavePractice()`(停節拍器、離開全螢幕、關練習)。
  練習卡片的 × 拿掉了(換分頁就是離開);拿掉後標題列要固定高度(`min-height` = × 的大小),不然「共 n 小節」出現時輸入板會跳 2px
- 入口打開練習卡片。- 入口打開練習卡片。練習時根音卡片、和弦清單、結果面板(`.info`)都收起來
- **和弦譜**(使用者要求,2026-11,取代原本的「現在 / 下一個」兩張圖與底下那排名稱):
  - 整組進行一次看完,**一行 4 小節**(樂手讀譜的習慣:4 個和弦一行、8 個兩行、12 小節藍調三行);`max-width:340px` 一行 2 格。
    每格 = 和弦名稱 + 第二行(斜線低音、拍數)+ 小張和弦圖(吉他圖寬最多 96px;鋼琴照 `practiceKbWindow` 整組同一段鍵盤)
  - **斜線和弦的低音寫在第二行**(A♭m7♭5 / 第二行 /C♭):窄手機一格只有 59~67px,整串 11px 也要 77px。
    名稱放不下時 `fitChartNames` 整張一起縮(字級一致,最小 11px),不用「…」。每格固定兩行高,譜不會高低不齊
  - 目前那格金框(播放中跟著拍子呼吸,`prGlowCard`)、下一格淡金框;播放中目前那格跑出畫面就捲回來(`syncPracticeChart`)

    播放中只選不跳拍。輸入板下面:「長度:整小節」(點一下 1 拍 → 2 拍 → … → 整小節)、刪除這格、完成。再點一次同一格 = 收起
  - **新增**:沒有和弦時譜上只有一個「+」格;有和弦時「+」格不顯示(不然 8 個和弦會為了一顆 + 多一整行),
    改用提示列右邊的「+ 新增」。按了之後「+」格出現在最後(新的和弦會放那裡),輸入板一直加在最後,倒退鍵刪最後一個
  - 「+」格裡放一張看不見的和弦圖撐住高度,跟和弦格子一樣高:加第一個和弦時下面的輸入板不跳(測試有抓)
  - 斜線(/)改的是**選中的那一格**,新增模式時是最後一個(`padTarget`)。快捷鍵 Backspace:有選格子就刪那格,否則刪最後一個
  - 輸入板沒選格子時不出現(平常看到的是乾淨的譜);在折疊機上選了下面的格子,輸入板在畫面外就自動捲過去(`revealPad`)
- **主音按鈕**(進行庫標題下,「主音 C ▾」,使用者回報:輸入板收起來後原本「換輸入板的根音就換調」變得找不到):
  點開是 12 個調(兩行六個),選了 = 進行庫換成那個調,**目前已經有進行的話整組一起移過去**(差幾個半音走最近的方向)。
  主音存在 `PRACTICE.key`,跟輸入板的根音 `PRACTICE.pad` 分開(點格子改和弦會動到 pad,不能連帶把進行庫換調)。
  移調 − / + 時主音跟著走。說明「選了會把目前的進行一起移調」固定獨佔第二行(中英文一樣兩行)
- **速度只有一組**:在和弦譜下面、開始鈕左邊(`tempoCtlHTML(false, true)`,id 是 prSlower / prBpmOut / prFaster,
  連點數字打拍子)。練習卡片裡原本也有一組,兩組會讓人以為是兩種設定,拿掉了
- **震動**(`#prHaptic`,設定第三行、加速選單左邊;存在 `harmonymap.haptic`,預設關):每一拍震一下、第一拍比較重。
  App 用 Capacitor Haptics(`app/package.json` 的 `@capacitor/haptics`),觸控裝置瀏覽器有 `navigator.vibrate` 就用它;
  都沒有(iPhone Safari、桌機)就不顯示這個開關。時間跟拍點同一個 setTimeout(聽到的時刻)。英文加速選項縮成「+5 / 2 loops」,
  不然 280 寬英文第三行會多折一行(中英文排版一致)
- **進行分頁不釘住**(`body.prog .topbar{position:static}`):和弦譜加輸入板在手機上太高,整頁一起捲。
  順序:和弦譜 → 提示 → 輸入板(選了才有)→ 拍點 → 速度與開始 → 進行庫 → 練習卡片(清除、文字框、儲存、設定)。
  按開始時和弦譜不在畫面上方就先捲回來。桌機兩欄:左邊練習卡片、右邊和弦譜
- **沒有調性選單,範例進行不另外佔版面**(使用者原本要求拿掉範例省版面;2026-11 要求加回「常用進行庫」,
  做法是文字框旁一顆「進行庫」按鈕,點開才出現面板,不多佔版面)。進行一開始是空的,
  用和弦輸入板、文字框或進行庫排;空的時候上方寫提示 + 一顆「從進行庫挑一組」大按鈕(`#prEmptyLib`,捲到進行庫),沒有開始鈕。
  提示原本會上下浮動,裡面有按鈕後不浮(移動中的目標不好點,Playwright 也點不到)
- **進行庫**(`PROG_LIB`,16 條)一律用級數寫,
  套用時以**輸入板目前的根音**當主音(小調進行 = 同字母的小調),換根音就換調,面板上寫出目前主音。
  套用 = 把 `G: I V vi IV` 填進文字框再走 `applyCustom`,所以跟自己打的一樣能移調、存起來。
  測試把每一條在 14 個主音拼法上都解析一次
- **進行庫直接放在「進行」分頁裡**(`#libCard`,在「現在 / 下一個」下面、練習卡片上面),不是浮動面板:
  上面分類按鈕(流行 8 / 古典與電影 5 / 爵士 4 / 藍調與搖滾 5 / 我存的,跟清單的分類鈕同一套樣式),
  下面一張張卡片(名稱 + 目前調的和弦,寬的時候自動排兩三欄),點了就載入並試聽。目前載入的那一條框起來(照實際和弦比)。
  **照風格分類,不照大小調**(分類軸只能一種,小調進行照常出現的風格分)。已存的進行在「我存的」
- 2026-11 重新檢查後刪掉三條重複的:王道進行(= 4536251 前半)、小調流行歌(= 從小和弦開始的流行歌,關係大調)、
  加次屬和弦的爵士循環(次屬和弦有自己的表)
- **進行庫的名稱要一看就懂**(使用者要求):寫「聽起來像什麼、用在哪裡」(流行歌萬用進行、古典曲子的結尾、
  壯闊收尾(電影、遊戲)、佛朗明哥下行…),不寫級數也不寫術語(王道、正格終止、安達魯西亞、turnaround 都換掉了)。
  名稱後面接**目前主音的實際和弦**(`progLibChords`,C G Am F),不接級數;連續相同的合成 ×n(藍調 C7×4 F7×2 …)。
  名稱裡不要寫特定的調(原本英文叫 Canon in D,旁邊卻是 C 的和弦,會看不懂)。測試檢查名稱裡沒有級數
- **和弦輸入板**跟根音卡片同一套按鈕:根音 + ♭ ♯ + 14 顆快速鍵,另外多一顆 **/**(轉位/斜線和弦):
  按 / → 下一個字母(+ ♭ ♯)是**最後一個和弦**的低音(C maj / E = C/E),低音 = 根音就回到原位。
  選好低音後再按字母 = 下一個和弦的根音(不然打完 C/E 按 G 會變成 C/G);選過低音再按 / = 重選,
  還沒選就再按 / = 取消。按和弦種類、刪除、清除、移調都會離開斜線模式。快捷鍵 / 同一套。
  **剛按根音、還沒按種類就按 / = 大三和弦**:C / B 三下就是 C/B(使用者嫌 C maj / B 四下太麻煩;
  斜線和弦絕大多數是大三和弦)。其他種類照舊先按種類:A min / G = Am/G。
  **非練習的根音卡片也有 /**(只在和弦分頁,音階分頁只有 ♭ ♯):那裡已經有選中的和弦,/ B 兩下就是 C/B;
  斜線模式記住按下當時的 `chordId`,換和弦或分頁就失效(`rootSlashState()`)。按根音再按和弦種類,
  就立刻把這個和弦加到進行最後面、試聽一次,新加的那個在進行列裡閃一下。輸入板的根音是
  `PRACTICE.pad`,不動練習中正在顯示的和弦。進行與「刪除最後一個 / 清除」同一列;
  文字框保留給斜線和弦(D/F#),跟輸入板同步,沒有套用鈕(Enter 或離開就套用)
- 下方卡片要**緊湊**(使用者要求「簡單、緊湊」):拍數、速度(− / + 每次 5 BPM,不是整排滑桿)、伴奏擠成一列,
  關閉是右上角 × 線稿圖示,說明文字收進開始鈕的 title。手機上整個練習畫面放得進一個螢幕(測試:卡片 ≤ 560px)。
  `.info` 是 display:flex,要另外寫 `.info[hidden]{display:none}` 才藏得起來(踩過);`.kb-wrap` 同理
- 進行庫每條長度一律 2 / 4 / 8 / 12 個和弦(一句的長度),循環時才不會卡一拍。原本小調低音半音下行 5 個、
  華語 4536251 7 個、爵士五度循環 6 個,都補成 8 個(測試會檢查)
- 節拍器用 Web Audio 時鐘提前 0.1 秒排程點擊聲,畫面用 setTimeout 對齊;第一拍重音、在第一拍換和弦。
  點擊聲不進 `scheduledNodes`。**第一拍的和弦也在排點擊聲的同一刻、用同一個音訊時鐘排**(`playCurrent(at)`),
  不能等畫面的 setTimeout 觸發才彈——計時器常晚幾十毫秒、playNotes 又再往後 60ms,
  實測和弦比點擊聲晚 63~71ms(使用者回報過)。有 `at` 時前一個和弦排在那一刻停,不是立刻切掉。
  測試會比對每個第一拍的點擊時間與和弦第一個音,差距要 < 1ms
- 切到音階或反查分頁要停止節拍器(`practiceStop`)
- **移調**:設定列的「移調 − / +」整組平移半音,根音拼法照常見調名(C D♭ D E♭ E F F♯ G A♭ A B♭ B,`PC_SPELL`),
  斜線低音存的是半音差所以跟著走
- **存進行**:目前這一組存在 `harmonymap.practice`(重新整理還在);「儲存」是開關(已存過就變「取消儲存」),
  已存的放 `harmonymap.progs`(字串陣列,跟文字框同一種寫法),存的進行在進行庫面板的「我存的」分類,文字用 textContent 填
- 鋼琴練習**不自動選轉位**(使用者要求):轉位只照輸入的名稱,沒有斜線就彈原位

## 節拍器與畫面更新(穩定性)
- 播放中每小節換和弦用 `practiceTick()`,只換和弦譜格子的 class(目前/下一個)、進行裡亮的那格與拍點;**不要**呼叫整個 `render()`——
  那會重建開始/停止鈕、文字框、輸入板:換小節那一刻按停止會點空,iPhone 上打字中的文字框每小節被收掉鍵盤
- `render()` 在練習時不重建根音列與和弦清單(都收起來了)
- 計時器被節流回來時(切背景、主執行緒卡住),錯過的拍子直接跳過、留在小節格線上,不一口氣補(`schedule` 開頭)
- `PRACTICE.runId`:停了又馬上開始,上一輪還沒觸發的 setTimeout 自己作廢
- 停止時取消「已經排好、還沒響」的下一個和弦(`playNotes` 幫每個音記 `_at`);正在響的不動
- 拍點與換和弦的畫面時間用 `heardTime()`(扣輸出延遲),跟鍵盤發亮同一個規則

## 級數輸入
- 文字框可以打級數:先寫調(`G:`、`Bb:`、`Am:`、`F#m:`),後面的羅馬數字照那個調換成和弦(`romanStep`)。
  大寫 = 大三、小寫 = 小三,`°`/`o` = 減、`ø` = 半減、`+` = 增,後面可以接記號(V7、ii7、Imaj7、IVsus4),前面可以加 ♭ ♯(♭VII)。
  小調的 III、VI、VII 照自然小調算(♭3 ♭6 ♭7)。根音照級數推字母(F♯ 大調 vii° = E♯dim),拼出來超過一個升降時退回常見拼法。
  沒寫調就打羅馬數字算錯字。存起來的是換好的和弦名稱(移調照舊能用)
- **斜線低音**寫在 / 後面,用「相對主音的大調級數」:`I/3` = C/E、`V/7` = G/B、小調 `i/♭7` = Cm/B♭(小調也照大調級數算,
  跟音階的級數記法同一套)。/ 後面不是 1~7 就算錯字
- 預備拍(`prCountIn`,存在 `harmonymap.countin`):開始時 `count` 從 −拍數 起算,這一小節只有點擊聲與拍點,不彈和弦、不換圖;
  第一個和弦落在下一小節第一拍
- 打拍子設定速度:連點 BPM 數字(`#prBpmOut`,pointerdown),取最近 4 個間隔平均,停超過 2 秒重算,40~200;播放中也能改
- 設定列在 320px 英文時會換成三行(卡片多 32px),仍在卡片高度限制內
- 逐漸加速(`#prRamp`,存在 `harmonymap.ramp`):固定 / 每輪 +2 / 每 2 輪 +5 / 每 4 輪 +5,最快 200。在新一輪第一拍換速度;
  停止時回到開始時的速度(`baseBpm`,手動 −/+ 或打拍子也會更新它)
- 一小節兩個和弦:步驟可以帶 `beats`(文字框寫 `C*2`),沒寫就是整小節。點進行裡的和弦在「整小節 ↔ 半小節」切換,晶片標「2拍」。
  排程照累計拍數換和弦(`practiceTimeline`),拍點與重音照小節格線;存檔/文字框用 `stepText`(保留 *n),畫面上的名稱用 `stepName`
- 吉他練習時設定列多一個移調夾選單(`#prCapo`;鍵盤設定面板練習時收起來了)。★ 標在這組進行開放和弦指型最多的格數
  (`practiceCapoBest`:夾 0~7 格各算一次最好指法是不是開放和弦,同分取低格;E♭ B♭ Cm A♭ → 夾 1 或 3)
- 兩欄版面(≥ 900px,橫式平板/桌機)練習時:練習卡片搬到上半部左欄(`placePracticeCard`,原本根音卡片的位置),
  右邊「現在/下一個」sticky 停在畫面上;圖高照視窗高度收(矮的 460px 也看得到開始鈕)、最寬 260px。
  `.topbar .kb-wrap{display:flex}` 會蓋過 hidden,要另外寫 `[hidden]{display:none}`,不然練習時一般鍵盤會露在下面
- 全螢幕練習(使用者要求,**只在橫式**):「現在/下一個」右上角的放大鈕(`#prFs`,直向時藏起來)。按下去蓋滿整個視窗
  (`#prFull`),只顯示和弦:一次四個(現在 + 後面三個,循環),現在那一個金框發亮,底下一排拍點;右上角播放/停止與離開鈕。
  iPhone Safari 不支援一般元素的 requestFullscreen,所以是 position:fixed 蓋滿;支援的瀏覽器另外進入真正的全螢幕。
  離開:右上角鈕、Esc、轉回直向、瀏覽器自己退出全螢幕、關掉練習。播放中每小節 `practiceTick` 也會更新全螢幕的四張

## 小鍵盤大小、速度/拍子快速調整
- 鋼琴小鍵盤(「現在/下一個」、全螢幕)**整組共用同一段鍵盤**(`practiceKbWindow`):起點 = 全組最低音下方最近的 C 或 F,
  長度照 8(一個八度)/ 11 / 15 個白鍵裡最小放得下的,再放不下就畫到全組最高音(補到 B 或 E)。「現在/下一個」同一個鍵上下對齊,
  看得出手要往哪裡移。使用者回報:C G Am Fm 在手機橫向全螢幕時鍵太小
- 單欄時小鍵盤的框固定是 11 鍵的比例(`aspect-ratio:154/56`):鍵數變了框不變高,加和弦時底下的輸入板不跳(測試有抓)
- **就近轉位**(`prVoice`,只有鋼琴,記在 `harmonymap.voicing`,預設關 = 照名稱的原位):第一個和弦原位,之後每個和弦試所有轉位 × 上下八度,
  取「每個音到前一個和弦最近的音」距離總和最小的,加上「離第一個和弦音區越遠越貴」(0.6 × 平均音高差)才不會繞幾圈一路飄高。
  斜線和弦的低音照樣在最下面(和弦內音 = 限定那個轉位;和弦外音 = 放在最低音下方一個八度內)。
  做法是 `withStep` 把算好的排法放進 `VOICED`,`displayNotes` 直接回傳它,所以圖、伴奏、點圖發聲都是同一個排法;整組算一次存在 `PRACTICE._vc`
- 全螢幕(橫式):**和弦位置固定,只移動亮框**(使用者要求:不要把現在的和弦搬到最左邊)。4 個以內照順序一排(有幾個排幾張);5~8 個上四下四(`.pf-grid.two`);
  超過 8 個每 8 個一頁,進行到下一頁才整頁換。直式的「現在 / 下一個」(一次兩張)照舊跟著進行輪換
