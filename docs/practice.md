# 換和弦練習

> 這份是從 CLAUDE.md 拆出來的細節規則,要改相關功能時才讀。整體的硬性規則在 CLAUDE.md。

## 換和弦練習
- 和弦分頁的「練習」鈕打開練習卡片。練習時根音卡片、和弦清單、結果面板(`.info`)都收起來
- **練習時上方釘住區的長指板/鍵盤換成「現在 / 下一個」兩張和弦圖**(`#practiceStage`,在 `.topbar` 裡)
  + 拍點 + 開始鈕(使用者要求)。點圖就聽那個和弦。桌機放在原本指板的位置(第二欄)
- **沒有範例進行、沒有調性選單**(使用者要求拿掉,省版面)。進行一開始是空的,
  用和弦輸入板或文字框自己排;空的時候上方寫提示、沒有開始鈕
- **和弦輸入板**跟根音卡片同一套按鈕:根音 + ♭ ♯ + 14 顆快速鍵,另外多一顆 **/**(轉位/斜線和弦):
  按 / → 下一個字母(+ ♭ ♯)是**最後一個和弦**的低音(C maj / E = C/E),低音 = 根音就回到原位。
  選好低音後再按字母 = 下一個和弦的根音(不然打完 C/E 按 G 會變成 C/G);選過低音再按 / = 重選,
  還沒選就再按 / = 取消。按和弦種類、刪除、清除、移調都會離開斜線模式。快捷鍵 / 同一套。
  **剛按根音、還沒按種類就按 / = 大三和弦**:C / B 三下就是 C/B(使用者嫌 C maj / B 四下太麻煩;
  斜線和弦絕大多數是大三和弦)。其他種類照舊先按種類:A min / G = Am/G。
  **非練習的根音卡片也有 /**(只在和弦分頁,音階分頁只有 ♭ ♯):那裡已經有選中的和弦,/ B 兩下就是 C/B;
  斜線模式記住按下當時的 `chordId`,換和弦或分頁就失效(`rootSlashState()`)。按根音再按和弦種類,
  就立刻把這個和弦加到進行最後面、試聽一次,新加的那個在進行列裡閃一下。輸入板的根音是
  `PRACTICE.pad`,不動練習中正在顯示的和弦。進行與「刪除最後一個 / 清除」同一列;
  文字框保留給斜線和弦(D/F#),跟輸入板同步,沒有套用鈕(Enter 或離開就套用)
- 下方卡片要**緊湊**(使用者要求「簡單、緊湊」):拍數、速度(− / + 每次 5 BPM,不是整排滑桿)、伴奏擠成一列,
  關閉是右上角 × 線稿圖示,說明文字收進開始鈕的 title。手機上整個練習畫面放得進一個螢幕(測試:卡片 ≤ 560px)。
  `.info` 是 display:flex,要另外寫 `.info[hidden]{display:none}` 才藏得起來(踩過);`.kb-wrap` 同理
- 「現在 / 下一個」的名稱放不下時(A♭m7♭5/C♭ 在 320px)兩格**一起**縮(`fitStageNames`,最多到 60%),字級維持一致
- 節拍器用 Web Audio 時鐘提前 0.1 秒排程點擊聲,畫面用 setTimeout 對齊;第一拍重音、在第一拍換和弦。
  點擊聲不進 `scheduledNodes`。**第一拍的和弦也在排點擊聲的同一刻、用同一個音訊時鐘排**(`playCurrent(at)`),
  不能等畫面的 setTimeout 觸發才彈——計時器常晚幾十毫秒、playNotes 又再往後 60ms,
  實測和弦比點擊聲晚 63~71ms(使用者回報過)。有 `at` 時前一個和弦排在那一刻停,不是立刻切掉。
  測試會比對每個第一拍的點擊時間與和弦第一個音,差距要 < 1ms
- 切到音階或反查分頁要停止節拍器(`practiceStop`)
- 上方「現在」那張和弦圖(`.pr-now .now`)與進行列裡現在的和弦,邊框都有金色光暈(使用者要求,兩者都要):停止時靜態,
  進行中跟著拍子一拍呼吸一次(`prGlow`,週期 `--beat` = 60/BPM 秒);`prefers-reduced-motion` 時不動
- **移調**:設定列的「移調 − / +」整組平移半音,根音拼法照常見調名(C D♭ D E♭ E F F♯ G A♭ A B♭ B,`PC_SPELL`),
  斜線低音存的是半音差所以跟著走
- **存進行**:目前這一組存在 `harmonymap.practice`(重新整理還在);「儲存」是開關(已存過就變「取消儲存」),
  已存的放 `harmonymap.progs`(字串陣列,跟文字框同一種寫法),有存才出現下拉選單。選單文字用 textContent 填
- 鋼琴練習**不自動選轉位**(使用者要求):轉位只照輸入的名稱,沒有斜線就彈原位
- 「現在 / 下一個」兩格**字級一致**(下一個只用顏色區分),兩個和弦的按法同時畫出來。
  吉他畫直式和弦圖,用的是指板上同一個指法(`chordVoicingsFor` 的第一個);
  鋼琴畫小鍵盤,**每張固定兩個八度(14 個白鍵)、寬度撐滿格子**,兩張永遠一樣大,
  而且**一定從 C 或 F 開始**(黑鍵分組完整,從 G、A 開始會讓人認錯鍵)

## 節拍器與畫面更新(穩定性)
- 播放中每小節換和弦用 `practiceTick()`,只換「現在 / 下一個」、進行裡亮的那格與拍點;**不要**呼叫整個 `render()`——
  那會重建開始/停止鈕、文字框、輸入板:換小節那一刻按停止會點空,iPhone 上打字中的文字框每小節被收掉鍵盤
- `render()` 在練習時不重建根音列與和弦清單(都收起來了)
- 計時器被節流回來時(切背景、主執行緒卡住),錯過的拍子直接跳過、留在小節格線上,不一口氣補(`schedule` 開頭)
- `PRACTICE.runId`:停了又馬上開始,上一輪還沒觸發的 setTimeout 自己作廢
- 停止時取消「已經排好、還沒響」的下一個和弦(`playNotes` 幫每個音記 `_at`);正在響的不動
- 拍點與換和弦的畫面時間用 `heardTime()`(扣輸出延遲),跟鍵盤發亮同一個規則

## 級數輸入
- 文字框可以打級數:先寫調(`G:`、`Bb:`、`Am:`、`F#m:`),後面的羅馬數字照那個調換成和弦(`romanStep`)。
  大寫 = 大三、小寫 = 小三,`°`/`o` = 減、`ø` = 半減、`+` = 增,後面可以接記號(V7、ii7、Imaj7、IVsus4),前面可以加 ♭ ♯(♭VII)。
  小調的 III、VI、VII 照自然小調算(♭3 ♭6 ♭7)。根音照級數推字母(F♯ 大調 vii° = E♯dim),拼出來超過一個升降時退回常見拼法。
  沒寫調就打羅馬數字算錯字。存起來的是換好的和弦名稱(移調照舊能用)
- 預備拍(`prCountIn`,存在 `harmonymap.countin`):開始時 `count` 從 −拍數 起算,這一小節只有點擊聲與拍點,不彈和弦、不換圖;
  第一個和弦落在下一小節第一拍
- 打拍子設定速度:連點 BPM 數字(`#prBpmOut`,pointerdown),取最近 4 個間隔平均,停超過 2 秒重算,40~200;播放中也能改
- 設定列在 320px 英文時會換成三行(卡片多 32px),仍在卡片高度限制內
- 逐漸加速(`#prRamp`,存在 `harmonymap.ramp`):固定 / 每輪 +2 / 每 2 輪 +5 / 每 4 輪 +5,最快 200。在新一輪第一拍換速度;
  停止時回到開始時的速度(`baseBpm`,手動 −/+ 或打拍子也會更新它)
- 一小節兩個和弦:步驟可以帶 `beats`(文字框寫 `C*2`),沒寫就是整小節。點進行裡的和弦在「整小節 ↔ 半小節」切換,晶片標「2拍」。
  排程照累計拍數換和弦(`practiceTimeline`),拍點與重音照小節格線;存檔/文字框用 `stepText`(保留 *n),畫面上的名稱用 `stepName`
- 吉他練習時設定列多一個移調夾選單(`#prCapo`;鍵盤設定面板練習時收起來了)。★ 標在這組進行開放和弦指型最多的格數
  (`practiceCapoBest`:夾 0~7 格各算一次最好指法是不是開放和弦,同分取低格;E♭ B♭ Cm A♭ → 夾 1 或 3)
- 兩欄版面(≥ 900px,橫式平板/桌機)練習時:練習卡片搬到上半部左欄(`placePracticeCard`,原本根音卡片的位置),
  右邊「現在/下一個」sticky 停在畫面上;圖高照視窗高度收(矮的 460px 也看得到開始鈕)、最寬 260px。
  `.topbar .kb-wrap{display:flex}` 會蓋過 hidden,要另外寫 `[hidden]{display:none}`,不然練習時一般鍵盤會露在下面
- 全螢幕練習(使用者要求,**只在橫式**):「現在/下一個」右上角的放大鈕(`#prFs`,直向時藏起來)。按下去蓋滿整個視窗
  (`#prFull`),只顯示和弦:一次四個(現在 + 後面三個,循環),現在那一個金框發亮,底下一排拍點;右上角播放/停止與離開鈕。
  iPhone Safari 不支援一般元素的 requestFullscreen,所以是 position:fixed 蓋滿;支援的瀏覽器另外進入真正的全螢幕。
  離開:右上角鈕、Esc、轉回直向、瀏覽器自己退出全螢幕、關掉練習。播放中每小節 `practiceTick` 也會更新全螢幕的四張

## 小鍵盤大小、速度/拍子快速調整
- 鋼琴小鍵盤(「現在/下一個」、全螢幕)**整組共用同一段鍵盤**(`practiceKbWindow`):起點 = 全組最低音下方最近的 C 或 F,
  長度照 8(一個八度)/ 11 / 15 個白鍵裡最小放得下的,再放不下就畫到全組最高音(補到 B 或 E)。「現在/下一個」同一個鍵上下對齊,
  看得出手要往哪裡移。使用者回報:C G Am Fm 在手機橫向全螢幕時鍵太小
- 單欄時小鍵盤的框固定是 11 鍵的比例(`aspect-ratio:154/56`):鍵數變了框不變高,加和弦時底下的輸入板不跳(測試有抓)
- **就近轉位**(`prVoice`,只有鋼琴,記在 `harmonymap.voicing`,預設關 = 照名稱的原位):第一個和弦原位,之後每個和弦試所有轉位 × 上下八度,
  取「每個音到前一個和弦最近的音」距離總和最小的,加上「離第一個和弦音區越遠越貴」(0.6 × 平均音高差)才不會繞幾圈一路飄高。
  斜線和弦的低音照樣在最下面(和弦內音 = 限定那個轉位;和弦外音 = 放在最低音下方一個八度內)。
  做法是 `withStep` 把算好的排法放進 `VOICED`,`displayNotes` 直接回傳它,所以圖、伴奏、點圖發聲都是同一個排法;整組算一次存在 `PRACTICE._vc`
- 全螢幕:4 個以內從現在這個開始輪流排 4 張;**5~8 個整組照順序排成兩排(上四下四)**,現在的那張亮框(`.pf-grid.two`)
- 速度:練習卡片、上方「現在/下一個」(開始鈕左邊 − BPM +)、全螢幕下方列(拍子選單、拍點、− 滑桿 BPM +)三處都能調,
  `practiceSetBpm` / `updateBpmUI` 同步所有 `[data-bpm-out]` 與滑桿。− / + 按住連續調(`bindRepeat`,0.4 秒後每 0.12 秒 ±5);
  BPM 數字連點 = 打拍子(`practiceTap`)。上方那塊沒放拍子選單(320px 放不下),拍子在卡片與全螢幕調
- **拍數**:點進行裡的和弦 = 整小節 → 1 拍 → 2 拍 → … →(拍號 − 1)拍 → 整小節(文字寫法 `C*1`、`C*3`)。
  **沒設拍數的和弦填到小節線**(`practiceTimeline` 的 dur):C*1 G Am F = 1 + 3 + 4 + 4 拍,後面的和弦不會被推離小節線;
  整個進行補到整小節(最後一個和弦延長)。自己設的拍數亮青、自動填的淡色;新小節開頭的和弦左邊畫小節線(`span.bar`,
  用 class 不插元素,進行的 children 索引 = 和弦索引);卡片標題旁寫「共 N 小節」(`#prBars`)
